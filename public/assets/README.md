# Assets

Brand SVGs. All use `currentColor` so they inherit text color — set the parent's `color` property to recolor.

| File | Use |
|---|---|
| `logo-mark.svg` | The circular AM monogram. 64×64 native. Use at 24-64px, never smaller than 20px or the inner glyph collapses. |
| `logo-wordmark.svg` | Horizontal `[mark] ANTI/MATRIX PROJECT` lockup. 360×56. Use in navigation. |
| `logo-stacked.svg` | Stacked version with tagline. For business cards, deck covers, hero zones. |
| `grid-bg.svg` | 64×64 tileable grid texture. Apply via `background: url(grid-bg.svg)`. |
| `aperture.svg` | Large concentric mark. Hero panels, loading states, "scanning" empty states. |
| `glyphs/aperture.svg` | 24×24 icon version of the aperture mark. |
| `glyphs/am-monogram.svg` | 24×24 AM glyph for favicons. |
| `glyphs/signal-arrow.svg` | The angled arrow + tail tick. Use for CTAs and "next" affordances. |
| `glyphs/tick-corner.svg` | The corner L-brackets, packaged as one icon. Used in instrument frames. |

## Replace with real logos
These marks are **originals built from the brief**. If the user has a real Anti Matrix Project logo, drop it in here with the same filenames and references throughout the system will pick it up. Note: the wordmark uses Space Grotesk Medium — if a real logo uses a different face, you'll want to replace the wordmark SVG with a real artwork file rather than the type-set version.
